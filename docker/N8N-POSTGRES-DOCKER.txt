n8n (Docker) ←→ PostgreSQL على Windows / Docker — حل Connection refused
================================================================================

المشكلة: داخل حاوية n8n، localhost = الحاوية نفسها وليس جهازك ولا قاعدة البيانات.

--------------------------------------------------------------------------------
أين تعمل PostgreSQL؟
--------------------------------------------------------------------------------

(1) PostgreSQL على نفس جهاز Windows (تطبيق مثبت أو Docker منفصل على المضيف)
    → في اعتماد Postgres داخل n8n استخدم:
       Host:     host.docker.internal
       Port:     5432
       Database: king_office_new
       User:     postgres
       Password: (كلمة المرور عندك، مثال للتجربة: 1234)
       SSL:      تعطيل (Disable) إن كان اتصالاً محلياً

(2) PostgreSQL في حاوية Docker على نفس ملف docker-compose مع n8n
    → Host = اسم الخدمة في compose (مثلاً: postgres أو db)، وليس localhost.

(3) Linux بدون host.docker.internal
    → شغّل n8n مع: --add-host=host.docker.internal:host-gateway
    أو استخدم IP الجهاز المضيف على الشبكة (مثلاً 192.168.x.x).

--------------------------------------------------------------------------------
التحقق من أن PostgreSQL يقبل اتصالاً من Docker
--------------------------------------------------------------------------------

- في postgresql.conf: listen_addresses = '*' أو يشمل واجهة الشبكة.
- في pg_hba.conf: سطر يسمح لشبكة Docker (مثلاً 172.16.0.0/12 أو 172.17.0.0/16)
  بـ md5 أو scram-sha-256.
- جدار ناري Windows: السماح بالمنفذ 5432 وارد من الشبكة الخاصة.

ملاحظة: ngrok يخص الوصول إلى واجهة n8n عبر HTTPS فقط؛ لا يغيّر إعدادات Postgres.
