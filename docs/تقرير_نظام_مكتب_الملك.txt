1. نظرة عامة على النظام
--------------------------------------------------------------------------------
نظام مكتب الملك هو نظام إداري متكامل لإدارة مكتب خدمة الإنترنت والمكاتب التجارية.
يتكون من:
- واجهة أمامية (Frontend): React 19 + TypeScript + Vite 6
- واجهة خلفية (Backend): Python FastAPI
- قاعدة بيانات: PostgreSQL (افتراضي) أو SQLite (اختياري)

الوظائف الرئيسية:
- إدارة المشتركين (FTTH و Wireless)
- إدارة المحفظة والتعبئة
- إدارة المواد والمبيعات
- إدارة البطاقات (Switch، Qi) والخطوط (SIM)
- إدارة الشركاء والموردين
- التقارير المالية
- لوحة التحكم
- إدارة المستخدمين والصلاحيات
- الوضع الليلي
- التقارير القابلة للطباعة (دائماً بالوضع العادي)

3. ملفات الجذر (Root)
--------------------------------------------------------------------------------

package.json
    الوظيفة: إدارة التبعيات وسكربتات التشغيل.
    السكربتات:
    - dev: تشغيل واجهة التطوير (Vite على المنفذ 5173)
    - dev:backend: تشغيل الخادم الخلفي (uvicorn على المنفذ 8000)
    - start: تشغيل الواجهة والخادم معاً (concurrently)
    - build: بناء المشروع للإنتاج
    - preview: معاينة البناء
    - clean:db: تنظيف قاعدة البيانات
    - dev_legacy: تشغيل server.ts (Express)

vite.config.ts
    الوظيفة: إعدادات أداة Vite للبناء والتطوير.
    - تكوين React و Tailwind CSS v4
    - المنفذ 5173، host 0.0.0.0
    - دعم متغير GEMINI_API_KEY
    - alias @ للجذر

tsconfig.json
    الوظيفة: إعدادات TypeScript للمشروع.

index.html
    الوظيفة: نقطة الدخول HTML للتطبيق.

server.ts
    الوظيفة: خادم Express بديل (قد يُستخدم للتطوير أو النسخ القديمة).

.env / .env.example
    الوظيفة: متغيرات البيئة.
    - الجذر: VITE_API_BASE_URL
    - backend: DATABASE_URL، SECRET_KEY، POSTGRES_*، إلخ.

--------------------------------------------------------------------------------

    - تخصيص الوضع الليلي: @custom-variant dark (&:where(.dark, .dark *))

    - قواعد الطباعة (@media print):
      * إجبار الوضع العادي (الفاتح) لجميع العناصر عند الطباعة
      * .dark, .dark * { background: white; color: #0f172a; }
      * إعدادات @page (A4، هوامش 1.5cm)

6. قاعدة البيانات
--------------------------------------------------------------------------------

6.1 نوع قاعدة البيانات
--------------------------------------------------------------------------------
- الافتراضي: PostgreSQL
  * config.py: DATABASE_URL = "postgresql://postgres:postgres@localhost:5432/king_office_new"
  * backend/.env.example: POSTGRES_HOST، POSTGRES_PORT، POSTGRES_USER، POSTGRES_PASSWORD، POSTGRES_DB

- الاختياري: SQLite
  * إذا ضُبط DATABASE_URL ليبدأ بـ sqlite:/// (مثل sqlite:///./maktb.db)
  * database.py يضيف connect_args={"check_same_thread": False} تلقائياً

6.2 الجداول الرئيسية
--------------------------------------------------------------------------------
- users: المستخدمون
- system_settings: إعدادات النظام (عتبات التنبيه، اسم المكتب، إلخ)
- wallet_transactions: معاملات المحفظة (FTTH، Wireless)
- subscribers: المشتركون
- subscriber_history: سجل المشتركين
- internet_zones: المناطق
- internet_fats: نقاط FAT
- subscription_categories: فئات الاشتراك (FTTH، Wireless)
- internet_materials: مواد قسم الإنترنت
- internet_material_sales: مبيعات المواد
- office_materials: مواد قسم المكتب
- office_customers: عملاء المكتب
- office_sales، office_invoices، office_payments، office_installments
- partners، partner_transactions
- suppliers، supplier_transactions
- card_wallet_transactions، card_purchases، card_sales
- expenses: المصروفات
- cashback_history: سجل الكاش باك
- sim_packages، sim_numbers، sim_sales، sim_inventory_transactions
- notifications: الإشعارات
- activity_log: سجل النشاط
