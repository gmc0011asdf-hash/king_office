# تقرير التوحيد والأمان - نظام مكتب الملك

## 1. الملفات التي تم حذفها

| الملف | السبب |
|-------|-------|
| `server.ts` | خادم Express مع SQLite - تم استبداله بـ FastAPI |
| `backend/scripts/seed_admin_sqlite.py` | خاص بـ SQLite فقط - لم يعد مطلوباً |

---

## 2. التغييرات الجوهرية

### 2.1 package.json

- **حذف:** `better-sqlite3`, `express`, `dotenv`, `@types/express`, `tsx`
- **حذف سكربت:** `dev_legacy` (كان يشغل server.ts)
- **الاحتفاظ:** React, Vite, Tailwind, Lucide, Recharts, Leaflet, وغيرها من مكتبات الواجهة فقط

### 2.2 backend/app/core/database.py

- **قبل:** دعم PostgreSQL و SQLite (connect_args لـ SQLite)
- **بعد:** PostgreSQL فقط - يرفع `ValueError` إذا لم يكن `DATABASE_URL` بصيغة `postgresql://`

### 2.3 backend/scripts/clean_db.py

- **قبل:** دعم PostgreSQL و SQLite
- **بعد:** PostgreSQL فقط - حذف دوال `clean_sqlite` و `_get_existing_tables` لـ SQLite

### 2.4 backend/scripts/init_db.py

- **قبل:** يتخطى إنشاء DB إذا لم يكن PostgreSQL
- **بعد:** يخرج بخطأ إذا لم يكن PostgreSQL

### 2.5 backend/app/core/db_bootstrap.py

- **تعديل:** تخزين كلمة مرور المدير مشفرة بـ bcrypt بدلاً من النص الصريح
- **تعديل:** البريد الافتراضي `admin@maktabalmalik.com`

### 2.6 backend/app/core/security.py

- **قبل:** دعم النص الصريح للتوافق مع bootstrap
- **بعد:** bcrypt فقط - لا مقارنة بالنص الصريح

### 2.7 backend/app/shared/auth_router.py

- **قبل:** `_password_matches` يقبل النص الصريح
- **بعد:** يعتمد على `security.verify_password` (bcrypt فقط)

### 2.8 ملفات البيئة

- **backend/.env.example:** PostgreSQL فقط
- **.env.example:** `VITE_API_URL=http://localhost:8000`
- **setup_new_machine.bat:** إنشاء `backend/.env` لـ PostgreSQL بدلاً من SQLite

## 3. ربط الواجهة بـ FastAPI

- **src/api/client.ts:** `API_BASE_URL = import.meta.env.VITE_API_URL || "http://127.0.0.1:8000"`
- جميع طلبات API تتوجه إلى `http://localhost:8000` (أو القيمة في `.env`)
- المسارات: `/api/auth/login`, `/api/subscribers`, إلخ.

---

## 4. الحماية المطبقة

| المستوى | الأداة | الحالة |
|---------|--------|--------|
| **تشفير كلمات المرور** | bcrypt | ✓ مفعّل |
| **الجلسات** | JWT (python-jose) | ✓ مفعّل |
| **CORS** | FastAPI CORSMiddleware | ✓ مضبوط (localhost، الشبكة المحلية) |
| **حقن SQL** | SQLAlchemy (Parameterized) | ✓ محمي |
| **التحقق من المدخلات** | Pydantic | ✓ مفعّل |
| **البيئة** | python-dotenv / pydantic-settings | ✓ الأسرار في .env |

---

## 5. التحقق بعد التنفيذ

1. **تشغيل PostgreSQL** وتأكد من وجود قاعدة البيانات
2. **ضبط `backend/.env`** مع `DATABASE_URL` الصحيح
3. **تشغيل:** `npm run start`
4. **فتح:** http://localhost:5173
5. **تسجيل الدخول:** admin@maktabalmalik.com / admin123
