## 🚀 التشغيل الأول (ثلاث خطوات فقط)

### 1. فك الضغط
فك ضغط ملف `king_office_source.zip` في المجلد المطلوب.

### 2. تعديل الإعدادات
- انسخ `backend/.env.example` إلى `backend/.env`
- عدّل القيم التالية:
  - `DATABASE_URL` — رابط اتصال PostgreSQL (مع كلمة مرور قاعدة البيانات)
  - `SECRET_KEY` — مفتاح سري (انظر `docs/INSTALL.md` لطريقة التوليد)
  - `ADMIN_INITIAL_PASSWORD` — كلمة مرور المدير (8 أحرف على الأقل)، أو اتركه فارغاً لتوليد كلمة عشوائية

### 3. تشغيل الإعداد
شغّل الملف:
```
setup_new_machine.bat
```
سيقوم السكربت بـ:
- التحقق من تثبيت Node.js و Python و PostgreSQL
- إنشاء البيئة الافتراضية وتثبيت التبعيات
- تهيئة قاعدة البيانات وإنشاء مستخدم المدير
- طباعة كلمة المرور إن تم توليدها تلقائياً
