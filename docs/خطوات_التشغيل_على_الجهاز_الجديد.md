# خطوات التشغيل على الجهاز الجديد

دليل تشغيل نظام مكتب الملك على جهاز جديد.

---

## المتطلبات المسبقة

قبل البدء، تأكد من تثبيت:

| البرنامج | الرابط | ملاحظة |
|----------|--------|--------|
| **Node.js** | https://nodejs.org | اختر الإصدار LTS |
| **Python** | https://python.org | فعّل "Add Python to PATH" أثناء التثبيت |

---

## الطريقة السريعة (موصى بها)

### الخطوة 1: نقل المشروع

انسخ مجلد المشروع بالكامل إلى الجهاز الجديد (مثلاً: `D:\king_office`).

### الخطوة 2: تشغيل الإعداد

انقر مرتين على الملف:

```
setup_new_machine.bat
```

ينفّذ السكربت تلقائياً:
- التحقق من Node.js و Python
- تثبيت تبعيات الواجهة (npm install)
- إنشاء البيئة الافتراضية لـ Python وتثبيت التبعيات
- إنشاء ملفات البيئة (.env)
- إعداد قاعدة البيانات

### الخطوة 3: تشغيل النظام

بعد اكتمال الإعداد، انقر مرتين على:

```
start_system_king_office.bat
```

### الخطوة 4: فتح النظام

افتح المتصفح على: **http://localhost:5173**

---

## الطريقة اليدوية

إذا أردت تنفيذ الخطوات يدوياً:

### 1. تثبيت التبعيات

```powershell
cd D:\king_office
npm install
```

### 2. إعداد الخادم الخلفي

```powershell
cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

### 3. إنشاء ملفات البيئة

- **جذر المشروع** `.env`:
  ```
  VITE_API_URL=http://localhost:8000
  ```

- **backend** `backend\.env`:
  ```
  DATABASE_URL=postgresql://postgres:كلمة_المرور@localhost:5432/king_office_new
  SECRET_KEY=supersecretkey-change-in-production
  ACCESS_TOKEN_EXPIRE_MINUTES=10080
  ```

### 4. إعداد قاعدة البيانات

```powershell
cd backend
.\venv\Scripts\activate
python scripts\init_db.py
python scripts\bootstrap_db.py
```

### 5. تشغيل النظام

**نافذة 1 – الخادم الخلفي:**
```powershell
cd backend
.\venv\Scripts\activate
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

**نافذة 2 – الواجهة الأمامية:**
```powershell
cd D:\king_office
npm run dev
```

### 6. فتح المتصفح

انتقل إلى: **http://localhost:5173**

## PostgreSQL مطلوب

النظام يعمل فقط مع PostgreSQL. لا يدعم SQLite.

1. ثبّت PostgreSQL من https://www.postgresql.org
2. أنشئ قاعدة بيانات جديدة (مثلاً: `king_office_new`)
3. عدّل ملف `backend\.env`:

   ```
   DATABASE_URL=postgresql://postgres:كلمة_المرور@localhost:5432/king_office_new
   SECRET_KEY=مفتاح_سري_قوي
   ACCESS_TOKEN_EXPIRE_MINUTES=10080
   ```

4. أعد تشغيل `setup_new_machine.bat` أو نفّذ سكربتات الإعداد يدوياً.

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| `Node.js غير مثبت` | ثبّت Node.js من الموقع الرسمي وأعد تشغيل الجهاز |
| `Python غير مثبت` | ثبّت Python مع تفعيل "Add Python to PATH" |
| `فشل npm install` | تأكد من اتصال الإنترنت، وجرّب `npm cache clean --force` ثم أعد المحاولة |
| `فشل pip install` | تأكد من تفعيل venv: `.\venv\Scripts\activate` |
| الصفحة لا تفتح | تأكد أن كلا الخادمين يعملان (المنفذ 5173 و 8000) |
| خطأ في قاعدة البيانات | تحقق من `DATABASE_URL` في `backend\.env` |
