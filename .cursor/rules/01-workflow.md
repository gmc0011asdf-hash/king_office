# Rule: Workflow

## Scope
Task lifecycle for all contributors and agents.

## Allowed Edits
- Use diagnose -> plan -> implement -> verify -> report.
- Keep patches cohesive and localized.

## Forbidden Edits
- No edits before identifying failing boundary.
- No broad formatting-only sweeps in fix tasks.

## Mandatory Workflow
- Capture reproduction.
- Trace source-of-truth path.
- Patch minimal layer.
- Verify and report.

## Output Format Before Implementation
- Problem summary.
- Planned file list.
- Expected side effects.
- Verification checklist.
