# Rule: Testing

## Scope
Validation strategy for modified scope.

## Allowed Edits
- Run focused checks on touched areas.
- Provide precise manual verification when needed.

## Forbidden Edits
- Do not report unrun tests as passed.
- Do not skip validation for persistence changes.

## Mandatory Workflow
- Select smallest reliable checks.
- Capture actual outputs.
- Report residual risk.

## Output Format Before Implementation
- Checks executed.
- Observed results.
- Residual risks.
