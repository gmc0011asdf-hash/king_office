# أدوات لمرة واحدة (اختيارية)

ملفات في هذا المجلد **ليست جزءاً من تشغيل التطبيق**. يمكن حذفها بعد الاستخدام دون أن يتأثر النظام.

| الملف | الوظيفة |
|--------|---------|
| `seed_zones_f191_f197_fats.py` | إضافة مناطق F191–F197 و FAT بأسماء T-1 … T-n حسب العدد المطلوب لكل منطقة |

## تشغيل سكربت المناطق

من جذر المشروع `king_office`:

```bat
cd backend
venv\Scripts\activate
python ..\tools\seed_zones_f191_f197_fats.py
```

يتصل بقاعدة البيانات عبر `backend/.env` (`DATABASE_URL`). يتخطى المناطق و الـ FAT الموجودة مسبقاً (آمن عند إعادة التشغيل).
